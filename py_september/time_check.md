## Выводы

- **list** — меееедленно: цикл Python + объекты `int`.
- **set** — на генерации медленнее list: hash + коллизии.
- **ndarray** — быстрее всех: C-буфер, без циклов Python.


g_ndarr_fast использует numpy.random.choice(), что выигрывает по времени и памяти в сравнении с random.sample в g_ndarr

|                    | random.sample         |	rng.choice          |
|--------------------|-----------------------|----------------------|
| Язык реализации	 | Python (цикл + set)	 | C (numpy)            |
| Алгоритм	         | O(k) с коллизиями	 | O(k) алгоритм Флойда |
| Типы данных	     | Python int (~28 байт) |np.int64 (8 байт)     |
| Генератор	Mersenne | Twister	             | PCG64 (быстрее)      |


Алгоритм Флойда: 
На итерации J мы генерируем число T в диапазоне [0, J]. Если T уже есть в множестве — это значит, что «слот» занят. Но тогда мы добавляем само J, потому что J ещё не могло быть добавлено раньше (на предыдущих итерациях мы рассматривали только числа меньше J).

Это гарантирует, что на каждой итерации мы добавляем ровно одно новое число, и за k итераций получаем ровно k уникальных чисел
