# Сравнение list / set / ndarray

## Условия

- `min_ = -1000000`, `max_ = 1000000`
- `NUMBER = 10`, `REPEAT = 10`
- `timeit.repeat`, время на один вызов (с)

## Результаты

| n       | g_arr (list) | g_set (set) | g_ndarr (ndarray) |
|---------|--------------|-------------|-------------------|
| 10^3    | 0.00962865   | 0.00193628  | 0.00072188        |
| 10^4    | 1.38098284   | 0.02285860  | 0.00884772        |
| 10^6    |              |             |                   |

## Выводы

- **list** — меееедленно: цикл Python + объекты `int`.
- **set** — на генерации медленнее list: hash + коллизии.
- **ndarray** — быстрее всех: C-буфер, без циклов Python.
- Разрыв растёт с `n`: при 10^6 ndarray быстрее в … раз.
